# 수업 게임 탐험소

초등학교 과목·단원·차시별 수업 게임을 모아 두는 사이트입니다.

- **학생**: 로그인 없이 태블릿으로 들어와 차시별 게임을 해요. 기록은 학생 기기 안에만 저장돼요.
- **선생님**: 전자칠판용 퀴즈쇼를 띄우고, 선생님용 페이지에서 차시표·성취수준·QR 코드를 확인해요.
- **게임 단계 = 성취수준**: 🧭 살펴보기(C) · 🔎 조사하기(B) · 🏅 분석하기(A)
- **탐험 리포트**: 성취기준별·영역별로 도달한 단계를 보여 주고 인쇄할 수 있어요. (과정 중심 평가 참고 자료)

## 문제 고치기·추가하기 (GitHub 웹에서)

모든 문제는 `src/content/games/` 의 YAML 파일에 있어요. `main` 브랜치에 저장하면 1~2분 뒤 사이트에 반영돼요.

문제 하나는 이렇게 생겼어요.

```yaml
- type: choice          # choice(하나 고르기) · multi(모두 고르기) · sort(바구니 나누기) · order(순서대로 놓기) · budget(예산 안에서 고르기) · pickmonth(그래프에서 달 고르기) · pin(지도에서 위치 고르기) · build(집·옷 꾸미기) · shop(상품 기획) · circuit(회로 꾸미기)
  lv: B                 # 게임 단계 = 성취수준 (C 살펴보기 · B 조사하기 · A 분석하기)
  std: 6사10-01         # 성취기준 코드
  cat: 지식·이해        # 지식·이해 · 과정·기능 · 가치·태도
  photo: landforms/sognefjord   # 사진 (src/data/photos.json 의 키)
  q: 송네 피오르는 어떻게 만들어졌을까요?
  hint: 📒 탐험 노트에 보일 도움말 (선택)
  options:
    - 빙하가 깎아 만든 골짜기에 바닷물이 들어와서
    - 강물이 실어 온 흙이 바닷가에 쌓여서
  answer: 빙하가 깎아 만든 골짜기에 바닷물이 들어와서   # 보기 글과 똑같이
  explain: 답을 확인한 뒤 보이는 설명 (선택)
  collect: [sognefjord]  # 맞히면 도감에 들어갈 지형 카드 (지형 도감만)
```

- 자료로 `table:`(표), `bars:`(막대그래프), `agebars:`(나이별 인구 구성 막대), `card:`(상황 카드)도 붙일 수 있어요. 예시는 `src/content/games/smart-choice.yaml`.
- 그래프 문제는 `chart: seoul` (한 개) 또는 `charts: [rome, seoul, london]` (비교)로 씁니다. 도시 자료는 `src/data/climate.json` 에 있어요.
- `hideChartName: true` 면 그래프 위에 도시 이름 대신 "어느 도시일까요?" / "그래프 가·나·다"가 보여요.
- 값에 `'`, `:`, `?` 로 시작하는 글이 있으면 큰따옴표로 감싸 주세요.

단원 정보(성취기준, 성취수준, 차시표, 지형 카드)는 `src/content/units/soc-6-2-1.yaml` 에 있어요.

과학 가상 실험실은 문제에 한 줄을 더하면 보여요: `sunday:`(하루 태양 고도·그림자·기온 표), `orbit: true`(공전 모형), `candle: true`(비커 덮기), `magnet: true`(전자석).

### 고친 뒤 검사하기

사이트를 만들 때(`npm run build`) 정답이 보기에 있는지, 바구니 이름이 맞는지, 스테이지마다 🧭🔎🏅 세 단계 문제가 다 있는지 등을 먼저 검사해요. 검사에 걸리면 배포가 멈추고 어느 파일 몇 번 문제인지 한국어로 알려 줘요. GitHub의 Actions 탭에서 빨간 ✗ 표시가 보이면 그 안내를 확인하세요. (내 컴퓨터에서는 `npm run check`)

> ⚠ 보기를 `[가, 나, 다]`처럼 한 줄에 쓸 때 보기 안에 쉼표(,)가 있으면 보기가 둘로 쪼개져요. 쉼표가 든 보기는 `- 보기` 처럼 한 줄에 하나씩 적어 주세요.

## 새 단원 추가하기

1. `src/content/units/` 에 단원 파일을 만들어요. (예: `math-4-1-2.yaml`, 기존 파일을 복사해 고치기)
2. `src/content/games/` 에 게임 파일을 만들고 `unit:` 에 단원 파일 이름을 적어요.
3. 개인용 게임은 `template: mission`, 전자칠판 게임은 `template: quizshow`(퀴즈쇼) · `zoomout`(줌아웃 사진) · `bingo`(빙고) 로 써요.

## 사진

사진은 `public/images/` 에 있고, 출처·라이선스는 `src/data/photos.json` 에 적어요. 위키미디어 공용의 자유 이용 사진(CC0·퍼블릭 도메인·CC BY·CC BY-SA)만 쓰고, 사이트의 **사진·자료 출처** 페이지에 자동으로 표시돼요.

과학 게임의 상황 그림 19장은 ChatGPT 계정으로 로그인한 Codex의 그림 생성 기능으로 만들었어요. 파일은 `public/images/illust/`에 있고, `photos.json`에 `"ai": true`로 적혀 있어요. 문제 아래에는 "그림: AI 생성", 출처 페이지에는 「AI로 만든 그림」으로 따로 보여요. 그림은 하나씩 과학적으로 맞는지 확인했어요. 콘센트 모양, 냉각탑 연기, 자기 부상 열차의 뜬 틈처럼 틀린 3장은 다시 만들었어요. 그림이 정답을 알려 주지 않도록 문제에 붙일 자리도 골랐어요.
